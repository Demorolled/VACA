# Grocery Price Radar

Scan or search products, track prices across nearby supermarkets, discover
real-time deals, and get alerts when a price drops.

- **Stack:** web-app (single-file HTML/JS, localStorage)
- **Run:** `python3 -m http.server 8000` in this folder, open http://localhost:8000
- **Idea source:** [turbostarter.dev/ideas/mobile/grocery-radar](https://www.turbostarter.dev/ideas/mobile/grocery-radar) (batch 2, leader-approved)
- **Status:** scaffolded — skeleton has product watchlist + price history + drop alerts

## Roadmap
- Barcode lookup (Open Food Facts API) for product metadata
- Nearby-store price feeds and real-time deal discovery
- Price-drop notifications (pair with Jarvis reminder/scheduler)
