# Doomscroll Break Button

Offline, one-click break from doomscrolling: press the big button, get a
random tiny action (stretch, breathe, drink water), do it. No login, no
accounts, no internet.

- **Stack:** python-app (tkinter, stdlib only)
- **Run:** `python3 main.py`
- **Idea source:** [Ugh Okay — maxbasev.com](https://maxbasev.com/blog/build/ugh-okay)
- **Status:** scaffolded (batch 1, leader-approved)

## Roadmap ideas
