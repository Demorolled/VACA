# Multi-Store Price Comparison Tracker

Log prices for the same item across stores, compare unit prices, watch
history, and get alerted when an item hits your target price.

- **Stack:** web-app (single-file HTML/JS, localStorage)
- **Run:** `python3 -m http.server 8000` in this folder, open http://localhost:8000
- **Idea source:** [rationalgo.ai price-comparison tracker](https://rationalgo.ai/resources/app-builder/make-price-comparison-tracker-with-ai) (batch 2, leader-approved)
- **Status:** scaffolded — skeleton has items, stores, price logging, unit-price comparison, cheapest-store highlight
