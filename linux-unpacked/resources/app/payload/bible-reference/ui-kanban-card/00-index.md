# ui-kanban-card — Kanban Card

> 🔩 ATOMIC COMPONENT · category: ui · language: typescript

## When to Use

Rendering a draggable card inside a kanban/trello-style board column

**Why:** Atomic card that renders content and reports drag intent via onDragStart/onDragEnd; board logic stays separate

## Semantic Metadata (find-me tags)

`kanban`, `board`, `card`, `drag`, `agile`

## Standardized Interface (contract)

```ts
export interface KanbanCardData { id: string; title: string; tags?: string[] }
export interface KanbanCardProps {
  card: KanbanCardData;
  onDragStart: (cardId: string) => void;
  onDragEnd: () => void;
}
```

## Code Chunk (single responsibility)

```tsx
export function KanbanCard(props: KanbanCardProps) {
  const { card } = props;
  return (
    <div
      className="kanban-card"
      draggable
      onDragStart={() => props.onDragStart(card.id)}
      onDragEnd={() => props.onDragEnd()}
    >
      <span className="kanban-card-title">{card.title}</span>
      {card.tags && (
        <div className="kanban-card-tags">
          {card.tags.map((t) => (
            <span className="kanban-tag" key={t}>{t}</span>
          ))}
        </div>
      )}
    </div>
  );
}
```
