## Code Chunk (single responsibility)

```tsx
export async function* readChunks(read: (offset: number, length: number) => Promise<Uint8Array>, total: number, chunkSize: number) {
  for (let offset = 0; offset < total; offset += chunkSize) {
    yield await read(offset, Math.min(chunkSize, total - offset));
  }
}
```
