🔑 Critical Issues

🔴 CRITICAL XSS Vulnerabilities in 3 apps

expense-tracker.html, chat-app.html, and kanban-board.html use innerHTML with unsanitized user input. This allows script injection via message text, transaction descriptions, and card titles.

Fix: Add HTML entity escaping before injecting user content.

🟡 HIGH Backend Reliability

Preview server went down during testing. No graceful degradation or offline fallback when backend is unavailable.

⚠️ Medium Issues

  • MED Timer drift — pomodoro, music-player, typing-test use setInterval(fn, 1000) which drifts. Use Date.now() differential instead.
  • MED No touch/drag support — Kanban drag & drop uses HTML5 DnD API which doesn't work on mobile.
  • MED Random chart colors — Dashboard bar chart picks random colors each render, confusing on auto-refresh.
  • MED CSV import mislabeled — expense-tracker says "Import CSV" but only handles JSON.

🟢 Low Issues

  • LOW Memory in undo stack — sketch-pad stores 50 full canvas snapshots (~20MB)
  • LOW Missing ARIA labels — All apps lack accessibility attributes
  • LOW Responsive inconsistency — Mixed breakpoints across apps (500px vs 600px vs 700px)
