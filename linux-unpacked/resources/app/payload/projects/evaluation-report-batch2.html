⚠️ Issues Found

🟡 MEDIUM — text-adventure.html: Self-XSS via player commands
addMessage() uses innerHTML for all messages including raw player-typed commands. Player typing <img src=x onerror=alert(1)> as a command triggers self-XSS. Fix: Use textContent for player messages, innerHTML only for pre-written narrator text.
🟢 LOW — whiteboard.html: roundRect() browser compatibility
Uses ctx.roundRect() which was added to Canvas API in 2022. Older browsers (Safari <15.4, Firefox <112) may not support it. Fix: Add polyfill fallback.
🟢 LOW — spreadsheet.html: Function() constructor for formulas
Uses Function() constructor to evaluate formulas (e.g., =SUM(A1:A5)). Safe for local single-user app but worth documenting.
🟢 LOW — All apps: Missing ARIA labels on interactive elements
Consistent with the previous batch. No aria-label or role attributes on buttons and inputs.
