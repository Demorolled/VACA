## 1. Universal Node Types (every program is built from these)

| Node | Purpose | Variants | Canonical files |
|---|---|---|---|
| `input` | Handle user input, validate, sanitize | CLI Args, HTTP Request, File Input, Form Input, WebSocket, Stdin | `src/input/index.ts`, `src/input/validation.ts` |
| `logic` | Business logic, processing, computation | Pure function, Pipeline, State machine | `src/logic/index.ts` |
| `database` | Data persistence, storage, retrieval | SQLite (default), PostgreSQL, JSON File, In-Memory | `src/db/schema.ts`, `src/db/repository.ts`, `data/app.db` |
| `ui` | User interface rendering | Web UI (React), Terminal UI (Bubble Tea), Desktop UI | `src/ui/App.tsx`, `src/ui/components/` |
| `api` | External service integration | REST, WebSocket, System command | `src/api/client.ts` |
